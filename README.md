# FINEDGE — Plataforma de Inteligencia Ejecutiva y Soporte a la Decisión (PuntoOne)

Plataforma ejecutiva de alto impacto construida con arquitectura **100% local-first** (Next.js 14, TypeScript, Tailwind CSS) diseñada para la defensa cuantitativa y auditoría de resultados de la firma **PuntoOne (Equipo FINEDGE)** en la simulación de negocios **Corbatul (Compañía Textil / Certificación ACBSP)** frente a 6 empresas rivales durante el periodo 2025-2029.

---

## Características de la Instancia FINEDGE

1. **Identidad Visual "Fintech Edge & Obsidian Precision":**
   * Paleta cromática ejecutiva de alto contraste: Fondo Obsidiana (`#060911`, `#0A0F1D`), verde esmeralda cuántico (`#10B981`), cian de precisión (`#06B6D4`), e índigo institucional (`#6366F1`).
   * Tipografía geométrica moderna con fuentes sans-serif nítidas y cifras contables estrictas en `font-mono tabular-nums`.
   * Tarjetas translúcidas con efectos glassmorphism (`edge-card`).

2. **Motor Causal de Decisiones (FSM de 3 Estados):**
   * **Diagnóstico Heredado:** Punto de partida de 2025 (Caja 2.52M€, capacidad 285k uds, valor 2,329.3 pts) y desafío crítico de margen en bufandas y calcetines.
   * **Animación Cinemática:** Procesamiento interactivo secuencial con radar de algoritmos.
   * **Pantalla Dividida 50% / 50%:** Decisiones en los 4 ejes (Comercial, Producción, Abastecimiento, Finanzas) a la izquierda frente a Resultados directos en la derecha.
   * **Modo Matriz Transversal:** Tabla comparativa consolidada de los 4 periodos simulados (2026-2029).

3. **Portafolio de Productos y Rigor Contable:**
   * **Corbatas:** Línea base con volumen de 235k uds y margen expandido al 50.3%.
   * **Bufandas:** Producto estrella de lujo ampliado a 55k uds con margen del 55.8% y precio de 29.20€.
   * **Calcetines:** Turnaround histórico de rentabilidad (de pérdida de -82.9% a margen positivo de +31.1% a 3.40€).
   * **Desapalancamiento Total:** Amortización anticipada del 100% de la deuda a largo plazo por tesorería propia.
   * **Valor de Compañía:** Ascenso histórico hasta **2,980.3 puntos** (Puesto #3 del ranking, liderando el factor de Resultados Económicos con 1,191 puntos).

## Ejecución Local

Desde este directorio:
```bash
# Iniciar servidor de desarrollo en el puerto 3002
npm run dev

# Compilar para producción
npm run build
```

O desde la raíz del proyecto global:
```bash
# Instancia Roura 1940 (Puerto 3000)
npm run dev:roura

# Instancia FINEDGE (Puerto 3002)
npm run dev:finedge
```

Abrir [http://localhost:3002](http://localhost:3002) en el navegador.
